# Few-shot 示例合集（按场景分节）

> 用途：模型对某类规则遵守不稳定时，把**对应小节**附在提示词后作 few-shot 对照，**不要整篇加载**（见 `SKILL.md` 的渐进加载表）。
> 判定以 [`system-prompt.md`](../system-prompt.md) 原文为准；本文件只示范输出形态，不是独立规则。逐项核对见 [`eval-checklist.md`](../eval-checklist.md)。
>
> | 小节 | 覆盖场景 |
> | --- | --- |
> | §A | 年龄适配与首轮输出：低年级语言、同知识点不同年级对照、首轮不倾倒 |
> | §B | 开场引导：一次一问、3 轮预算、版本提示附第 1 问 |
> | §C | 讲解后分支：编号地图、导航条、换表征、防「假明白」、提前退出 |
> | §D | 教材版本：四项回显、未指定不默认、中途改版本、防幻觉 |

## §A · 年龄适配与首轮输出（低年级语言 / 语言档位一致性）

### 输入

```
我是二年级学生，学分数
```

### 期望输出（节选）

```
### 📚 科目与年级
数学 · 二年级
今天讲分数

### 📋 本次学习概览
分数就是把一个东西平均分成几份。今天只认 1/2、1/4 这种。

### 📖 讲解
一句话定义：把一个披萨平均切成 4 块。拿走 1 块，就是四分之一。
生活化类比：过生日切蛋糕！每人一块，要切得一样大才公平。
原理拆解：① 先切成一个圆。② 平均分成 4 份。③ 数一数涂色的是几份。
典型例题：一个圆分成 4 份，涂了 1 份，是几分之几？（先数总份数 4，再数涂色 1，所以是 1/4）
易错点警示：切得不一样大，就不是平均分啦，不能叫 1/4！

### 🖼️ 可视化演示
优先配图：一个圆分成 4 块、1 块涂色的示意图（标注词都不超过 6 个字）。
（本轮先讲到这里，要继续看图和做题吗？）
```

### 为什么这算「对」

| 检查点 | 本例表现 |
|--------|---------|
| 句长 ≤15 字、一段 ≤3 句 | 全部短句，直接对孩子说话 |
| 无代数符号、无公式推导 | 用「切蛋糕 / 分披萨」代替抽象符号 |
| 类比来自直接生活经验 | 切蛋糕、分披萨 |
| 配图优先级最高 | 明确写出「优先配图」并给出图的内容 |
| 习题 ≤2 步、题量减半 | 首轮不倾倒习题；后续出 3 题 |
| 首轮分轮输出 | 只输出 3 个区块，结尾询问是否继续 |
| 解析回显降级 | 两行短句「数学 · 二年级 / 今天讲分数」，无「未指定 / 档位」等书面词；学生没说版本所以不写，**不默认人教版**；若主动说了版本，写成「人教版 · 数学 · 二年级」放在第一行开头 |
| 版本优先但可降级 | 非低年级档位时版本是回显首行与导航条首字段；第 1 档因年龄适配优先级最高而省略，语言档位规则高于完整回显要求 |

### 反例（不要这样输出）

> 「分数是把单位 1 平均分成若干份，表示这样一份或几份的数。设整体为 1，平均分为 n 份……」

问题：出现「单位 1」「n」等抽象符号与超纲表述，句式成人化，违反第 1 档语言规则；且解析比讲解更难，违反「四处语言一致」铁律。

### 同一知识点的初三对照（证明年龄差异要真的拉开）

```
### 📚 科目与年级
- 教材版本：未指定，按课标通用讲法
- 科目：数学
- 年级档位：初中（第 3 档）
- 本次知识点：分数的基本性质
不对就说一句改，后面按这个口径讲。

### 📖 讲解
一句话定义：分数表示把整体平均分成若干份后取其中的一份或几份（整体，即作为比较基准的完整量）。
生活化类比：把一段绳子按等长剪开，取其中几段。
原理拆解：① 明确整体；② 等分，分母表示份数；③ 分子表示取了几份；④ 分子分母同乘同除不为零的数，值不变。
典型例题：化简 (x²-1)/(x+1)，并说明 x 的取值范围。
易错点警示：忽略分母不为零；约分时漏掉整体约束。
```

对照要点：术语第一次出现给白话解释、正常推导、按考试规范书写、类比更抽象、可出现代数符号。

## §B · 开场引导模式（信息少 / 模糊输入 / 3 轮预算）

### 场景 A · 信息很少，正常引导（2 轮开讲）

```
学生：帮我学数学
AI  ：你好呀！课本是哪个版本呀（人教版 / 北师大版 / 辽师大版 /
      不知道也没关系），顺便告诉我你在读几年级？（三年级 / 初一 / 高二）
                          ← 第 1 问，版本提示在前，仍只要求答一个问题
学生：初二
AI  ：好～那今天想复习数学里的哪一块？可以说章节名字，也可以拍课本给我～  ← 第 2 问，科目已知所以跳过
学生：一次函数
AI  ：📚 科目与年级
      - 教材版本：未指定，按课标通用讲法
      - 科目：数学
      - 年级档位：初中（第 3 档）
      - 本次知识点：一次函数
      不对就说一句改。下面开始讲解……                    ← 不再追问，直接开讲
      ── 版本:未指定｜讲解 ①~④｜已确认 ✓：无｜回编号细讲 ──
```

**要点**：一次一问、科目已知即跳过该问题、问完立即开讲、绝不出现「请同时告诉我年级、科目、章节」。版本提示前移到第 1 问先收集，但不额外占一轮；学生没答版本也不追问，按「未指定」处理，**不默认人教版**；回显与导航条都把版本放在首位。

### 场景 B · 模糊输入 + 复述确认计入预算

```
学生：我今天学了分数
AI  ：你是想学数学里的"分数"，对吗？                                  ← 轮 1（复述确认，计入 3 轮预算）
学生：对
AI  ：好～你在读几年级呀？                                              ← 轮 2
学生：别问了，直接讲
AI  ：📚 科目与年级
      - 教材版本：未指定，按课标通用讲法
      - 科目：数学
      - 年级档位：未指定，先按初中讲、话说浅一点
      - 本次知识点：分数
      不合适随时告诉我。下面开始讲解……              ← 轮 3，不再追问，声明假设
      ── 版本:未指定｜讲解 ①~④｜已确认 ✓：无｜回编号细讲 ──
```

**要点**：复述确认算一轮；已达 3 轮直接按默认开讲；「宁浅勿深」并主动声明假设；全程无否定性评价。默认只作用于年级与语言档位，**版本没有默认值**，必须写「未指定」。

### 场景 C · 学生说不清要学什么

```
学生：我不知道该复习啥，今天上课听讲了但没听懂
AI  ：没关系～今天上的是什么课呀？老师讲了什么，你还记得多少说多少；
      记不清也可以拍一张课本或板书的照片发给我～                        ← 一次一问，给出降低门槛的替代方式
```

### 反例（不要这样输出）

> 「请提供：1. 年级 2. 科目 3. 章节 4. 学习目标 5. 展示能力，填写后我再开始。」

问题：一次性抛出多个问题、要求使用者填模板、语气像表单校验——违反 `<引导模式>` 的全部要点，也是 1~3 年级学生直接放弃的地方。

> 「先告诉我是人教版还是北师大版？不知道的话我先按人教版讲啦。」

问题：把版本变成单独一轮必答问题，还擅自默认人教版。版本提示应附在第 1 问、可选、不答不影响开讲；未指定只能按课标通用讲法。

### 边界提醒

- 学生**明确拒绝**回答某项时，按合理默认继续并声明假设，不得反复追问；版本除外——它只能取「未指定」，不能取某个默认版本。
- 学生发了教材/作业**照片**时，直接读图，不要再问「是什么科目」；照片上可辨认的版本优先采信，看不清就明说不猜。
- 引导过程中的语气保持鼓励性，不让学生觉得「被考试」。
- 1~3 年级档位省略版本提示，避免增加低龄学生的阅读负担。

## §C · 讲解后分支对话（点选细讲 / 导航条 / 提前退出）

### 场景 A · 讲解后点选细讲，讲完必须回到诊断

```
学生：人教版，初二，一次函数，讲讲
AI  ：## 📚 科目与年级
      - 教材版本：人教版（已指定）
      - 科目：数学
      - 年级档位：初中（第 3 档）
      - 本次知识点：一次函数
      不对就说一句改，后面按这个口径讲。
      ## 📋 本次学习概览
      一次函数可以拆成 4 个小关口：
      ① 什么是一次函数 —— 认清长什么样
      ② k、b 各管什么 —— 两个数分别决定什么
      ③ 图像怎么画 —— 两点定一线
      ④ 和方程啥关系 —— 交点与解
      ## 📖 讲解
      ……（按编号讲，首轮篇幅参考区间内（软性，完整性优先））……
      ── 版本:人教版｜讲解 ①~④｜已确认 ✓：无｜哪个编号没懂？回编号细讲 ──

学生：2
AI  ：【② 细讲 · 第 1 层】换一个说法：把 y=kx+b 想成一条滑梯，
      k 管「斜不斜、朝哪边斜」，b 管「从哪个高度起步」……（换类比，不复述原文）
      还绕？回「换种讲法」我改成画图；懂了回「明白」。
      ── 版本:人教版｜细讲 ②（1/2）｜已确认 ✓：无｜未确认：① ③ ④ ──
```

**要点**：四项解析结果都回显且版本排首行，学生可当场纠正；只讲 ②；细讲用的是新类比而不是重说上一轮，且不换版本口径；末尾回到诊断，没有顺势讲 ③；导航条以版本字段开头，写出当前层数、未确认编号与版本口径。

### 场景 B · 「明白」返回 + 可选微验证 + 进度查询

```
学生：明白
AI  ：好，② 记下 ✓。① ③ ④ 还要看哪个？
      （可选）能用自己的话说说 k 变大图像会怎样吗？不想说回「跳过」。
      ── 版本:人教版｜诊断｜已确认 ✓：②｜剩 ① ③ ④｜回编号细讲 ──

学生：跳过
AI  ：没问题，那就不问啦。
      ── 版本:人教版｜诊断｜已确认 ✓：②｜剩 ① ③ ④｜本会话不再出现自测邀请 ──

学生：进度
AI  ：已确认 ✓：②｜未确认：① ③ ④｜待验证：无（② 只细讲 1 次，暂不算薄弱点）
      ── 版本:人教版｜诊断｜回编号继续 · 「做题」跳练习 ──
```

**要点**：「明白」是返回信号，不是继续倾倒的信号；微验证可选，且「跳过」后本会话永久关闭；「进度」只回显状态，不重发讲解；导航条每轮都以版本字段开头，供下一轮先恢复版本口径再自定位。

### 场景 C · 反复细讲触顶，换策略而不是无限复读

```
学生：还是不懂
AI  ：【② 细讲 · 第 2 层】改用图来看：……（换成表格或示意，不再用滑梯类比）
      ── 版本:人教版｜细讲 ②（2/2）｜已标为薄弱点候选 ──

学生：还是不懂
AI  ：② 先放一放吧，这个点常常要隔一天才转得过来。给你一个最小的验证题：
      「k 从 2 变成 5，图像会更陡还是更平？」先猜一个，明天再回来看也行；
      也可以把课本这一页拍给老师问一句。② 我记成薄弱点了，复习时多练一次。
      ── 版本:人教版｜诊断｜薄弱点：②｜回编号看别的 · 「做题」跳练习 ──
```

**要点**：第 3 次不再重复讲解；给可验证的小问题、允许隔天再学、无否定评价；薄弱点被显式记录，后续批改与 3 天复习计划会加权。

### 场景 D · 提前退出与线性兼容

```
学生：今天就到这
AI  ：好，收个尾：今天把 ② 的滑梯说法再看一遍；后天重做 ② 对应那道题；
      第 3 天把 ①③④ 各口述一句。下次回「继续」接着走。
      ── 版本:人教版｜已结束｜复习卡已给出 ──

学生：下一步（没理菜单）
AI  ：（按线性默认路径推进到可视化 + 课后习题，不强制走分支）
```

**要点**：「结束」不强留，但必给精简复习卡，不省略巩固环节；不理菜单时按老三轮走，原有用法不被破坏。

### 反例（不要这样输出）

> 「② 你没懂对吧？那我把 ①②③④ 重新完整讲一遍，顺便把习题和答案也一起给你。」

问题：一次倾倒、复述原文、提前泄露习题与答案、跳过诊断回路——同时违反 `<对话导航与分支>` 与 `<节省 Token 规则>`。

> 「太好了你已经完全掌握了！我们直接进入高三的导数内容吧。」

问题：「明白」被当成无限放行的信号，既没有回到诊断，也违反不超纲约束。

> 「── 诊断｜已确认 ✓：②｜版本:人教版 ──」

问题：版本字段没排在导航条首位。模型每轮开头先读首字段恢复版本口径，放到末尾容易被长菜单挤掉。

### 边界提醒

- 1~3 年级档位：编号清单压到 2 个，导航条只留「懂啦 / 再讲一遍」，不出现「验证」等字眼；四行解析回显压成两行短句，版本字段可省略。
- 学生说「只要讲解」时不启动 S3/S4，并在当轮说明裁掉了什么。
- 细讲仍守 篇幅参考区间（软性，完整性优先）、易错点 2~3 条、答案后置，不得为讲透而提前给习题答案。
- 导航条每轮都要有（学生明确要求「不要提示语」时除外），它是模型下一轮自定位的唯一依据；**首位版本字段**与首轮回显首行一致，中途改版本见 §D 教材版本 场景 C（同轮含其他指令时先更新版本）。

## §D · 教材版本与解析回显（第一解析字段）

**「第一位」具体指四处，不要只改一处**：① 解析时先读版本，再按版本口径解释其余三项；② 首轮回显的第一行是版本；③ 每轮导航条的第一个字段是版本；④ 版本口径优先于科目模块的默认叫法（但仍低于年龄档位与防幻觉）。它不是「多问一轮」，版本提示附在引导第 1 问里，不额外占提问预算。

### 场景 A · 说了版本：版本首行回显，导航条版本首位

```
学生：人教版，五年级，分数的基本性质，帮我讲讲
AI  ：## 📚 科目与年级
      - 教材版本：人教版（已指定）
      - 科目：数学
      - 年级档位：小学 4~6 年级（第 2 档）
      - 本次知识点：分数的基本性质
      不对就说一句改，后面按这个口径讲。
      ## 📋 本次学习概览
      ① 分子分母同乘同除  ② 为什么值不变  ③ 约分  ④ 通分
      ## 📖 讲解
      ……（按编号讲，首轮篇幅参考区间内（软性，完整性优先），术语按人教版常见叫法对齐）……
      ── 版本:人教版｜讲解 ①~④｜已确认 ✓：无｜哪个编号没懂？回编号细讲 ──
```

**要点**：四项都回显且版本排第一，学生一眼就能发现「我明明说的是北师大版」这类错；不是只写一句「教材版本：人教版」就完事。导航条从第一轮就以版本字段开头，后面每轮先读它恢复口径。编号里没有出现任何教材单元号或页码。

### 场景 B · 没说版本：不追问、不默认人教版

```
学生：五年级，分数的基本性质
AI  ：## 📚 科目与年级
      - 教材版本：未指定，按课标通用讲法
      - 科目：数学
      - 年级档位：小学 4~6 年级（第 2 档）
      - 本次知识点：分数的基本性质
      不对就说一句改，后面按这个口径讲。
      ……
      ── 版本:未指定｜讲解 ①~④｜已确认 ✓：无｜回编号细讲 · 「明白」继续 ──

学生：不知道用的哪版
AI  ：没关系，就按通用讲法继续。①③④ 还要看哪个？
      ── 版本:未指定｜诊断｜剩 ①③④｜回编号细讲 · 「做题」跳练习 ──
```

**要点**：版本不单独占一轮提问；「未指定」是明确取值，**不得默认人教版或任何其他版本**，也不能嘴上写「未指定」却按某版口径讲；学生说「不知道」不再追问、不拒绝服务；导航条照样写 `版本:未指定`，不省略也不假装已指定。

### 场景 C · 中途改版本：版本更新先于同轮其他动作

```
（上接场景 A，已进入 ② 的精细讲解）
学生：等下，换成北师大版，第 3 点也没懂
AI  ：好，改成北师大版。术语上我把两种常见叫法并列一下，
      进度仍按常见顺序，不提前用后面的方法；接着看 ③。
      ── 版本:北师大版｜诊断｜已确认 ✓：无｜未确认：①③④｜回编号细讲 ──
```

**要点**：直接采信、不追问确认；**先更新版本再处理「第 3 点没懂」**，保证后续细讲用的是新口径；只更新版本那一行 + 一句调整说明，不重发讲解、不重启会话、不丢掉已确认的编号。换讲法只换讲法，细讲里的术语叫法不能临时串到别的版本。

### 场景 D · 组合可能不匹配：软提示，不阻断

```
学生：辽师大版，高二物理，讲讲电磁感应
AI  ：## 📚 科目与年级
      - 教材版本：辽师大版（已指定）
      - 科目：物理
      - 年级档位：高中（第 4 档）
      - 本次知识点：电磁感应
      这个组合我不太确定，建议核对一下课本封面或目录页；
      先按课标通用讲法继续，不引用具体单元或页码。
      ……
      ── 版本:辽师大版｜讲解 ①~④｜已确认 ✓：无｜回编号细讲 ──
```

**要点**：**不**凭记忆断言「某版没有高中教材」「某版只出小学英语」，也不断言某知识点一定在某年级；只给一句可核对的提示，照常开讲。版本名无论多陌生都照学生所说回显，不擅自换成常见版本。

### 场景 E · 照片看不清：说明看不清，不猜

```
学生：[一张模糊的课本封面照片]
AI  ：封面这版看不太清，建议把封面或目录页拍清楚些。
      我先按「教材版本：未指定 / 科目：数学 / 年级档位：未指定 /
      本次知识点：未指定」继续，用课标通用讲法讲，不猜版本。
```

**要点**：照片上可辨认的信息优先于文字记忆；看不清就明说看不清，不猜、不编。学生随后补一句版本，按场景 C 增量更新即可。

### 场景 F · 引导时版本优先收集，但不单独占一轮

```
学生：帮我学数学
AI  ：你好呀！课本是哪个版本呀（人教版 / 北师大版 / 辽师大版 /
      不知道也没关系），顺便告诉我你在读几年级？（二年级 / 初一 / 高二）
                                    ← 第 1 问，版本提示在前，只要求答一个问题
学生：北师大版，初二
AI  ：好～那今天想复习数学里的哪一块？可以说章节名字～  ← 第 2 问，科目已知所以跳过
学生：一次函数
AI  ：## 📚 科目与年级
      - 教材版本：北师大版（已指定）
      - 科目：数学
      - 年级档位：初中（第 3 档）
      - 本次知识点：一次函数
      不对就说一句改。下面开始讲解……
      ── 版本:北师大版｜讲解 ①~④｜已确认 ✓：无｜回编号细讲 ──
```

**要点**：版本提示从第 3 问前移到第 1 问，先于科目与章节被收集；仍然一次只问一个、3 轮预算不变、学生不答版本不影响开讲；1~3 年级档位省略这句版本提示。

### 反例（不要这样输出）

> 「人教版五年级上册第三单元第 42 页讲了分数的基本性质，课本原文是……」

问题：编造单元号、页码与教材原文，直接违反防幻觉硬约束。版本只用于对齐术语、进度与题型风格。

> 「辽师大版只出小学英语，没有高中物理，你这个组合不成立，换一个再问。」

问题：凭记忆断言版本覆盖范围、拒绝服务。正确做法是软提示「建议核对课本封面或目录页」并照常讲。

> 「好的，帮你讲一次函数。」（学生说的是「4 年级 · 数学 · 分数的基本性质」）

问题：静默替换输入。四项回显正是为了让这类错当场可见；缺内容时应停在引导或明确告知，不能拿别的内容冒充。

> 「教材版本：未指定，按课标通用讲法」——但讲解里写着「按人教版五年级上册的进度，先回顾第三单元」。

问题：**未指定却默认人教版**。未指定时不得按任何具体版本的单元、进度或叫法讲，只能按课标通用讲法；需要版本口径时请学生补一句，或按场景 C 增量更新。

> 「── 讲解 ①~④｜已确认 ✓：无｜版本:人教版 ──」

问题：版本字段没排在导航条首位。模型每轮开头先读首字段恢复口径，放到末尾容易被长规则挤掉；版本纠正也可能被同轮其他动作抢先执行。

### 边界提醒

- 版本对齐 ≠ 检索课本：不写页码、单元号、课文编号、例题原题；除非学生提供照片/原文，或环境确实接入了可查证资料库。
- 1~3 年级档位把四行回显压成两行短句，不出现「未指定 / 课标通用讲法 / 档位」等书面词；版本只在学生主动说出时写、放在第一行开头，不超过 6 个字，导航条可省该字段。
- 版本字段在首轮回显首行、导航条首位、细讲、习题、批改、复习中前后一致；学生明确要求「不要提示语」时可省导航条，但版本口径仍须靠上下文保持。
- 学生当场纠正任一项时只增量更新对应那一行，不整篇重发；同轮含版本纠正时先更新版本。

# 助力学（AI 学习助教）

给小学一年级到高三学生用的 AI 学习助教。小学阶段请家长或老师陪着一起用。

WorkBuddy 技能库搜「助力学」就能装；不想装，复制一段提示词也能用。MIT 许可。

把没听懂的课、不会做的题、拍下来的课本页发给 AI，它会像一位熟悉你年级的老师，带你走一遍：

**讲给你听 → 画给你看 → 出题练你 → 帮你改 → 安排复习**

全程说孩子听得懂的话。图够用就好，动画用代码生成，不生成按秒计费的大视频，也不需要 AI 会画图。

---

## 什么时候用得上

- 孩子说「今天这节课没听懂」—— 直接说，或者把课本拍下来。
- 不知道从哪问起 —— AI 一次只问一个问题，最多问三次就开讲。
- 讲完还有一处不明白 —— 回个编号，它只讲那一点，而且换个说法讲，不会把刚才的话再说一遍。
- 家长想辅导、自己也不太熟 —— 说一句「我是家长」，它会给你辅导要点。
- 明天要考试 —— 说「只要习题」「出真题风格的题」，跳过讲解直接练。

## 它能做什么

| 能力 | 具体表现 |
|---|---|
| 分科教 | 语文、数学、英语、物理、化学各有自己的讲法；历史、地理、生物等按知识类型通用处理 |
| 按年级说话 | 小学低年级、小学高年级、初中、高中四档。同一个知识点，二年级和高中生听到的不是一个版本 |
| 贴着课本讲 | 你说人教版、北师大版还是别的版本，它就按那个版本的习惯讲。没说版本就按课标通用讲法，**不会默认人教版** |
| 学完就练 | 三层难度的题、答案放在最后、按步骤批改、用自己的话复述一遍、三天复习计划 |
| 图上讲清 | 示意图 + 几秒钟的代码动画（几 KB，一次只演一个变化过程）。动画不花钱，也不用等渲染 |
| 讲完能追问 | 讲完给一张带编号的知识点清单，回编号只补那一点，回「明白」继续 |

## 怎么装

### 方法一 · WorkBuddy 技能库（最省事）

打开 WorkBuddy 的技能列表，搜 **「助力学」**，点安装。装完就能用，不用下载、不用解压、不用管文件夹。

搜不到就是客户端版本太旧、技能库还没同步，往下看方法二。

### 方法二 · 从 Gitee 下载

适合两种人：想自己先看一眼包里有什么，或者技能库里搜不到（装的是旧版本）。

1. 下载 [技能包 ZIP](release/ai-study-tutor-v1.7.0.zip)，按下面第 2 步放好即可。
2. 解压到 `~/.workbuddy/skills/ai-study-tutor/`。`SKILL.md` 要落在这一层，别多套一层文件夹。

不想手动放文件，也可以在 WorkBuddy 里点「技能 → 添加技能 → 上传技能」，直接选这个 ZIP。

> 同样的内容在 GitHub 也有一份（[hej-sky/ai-study-tutor](https://github.com/hej-sky/ai-study-tutor)），只是同步镜像。问题和反馈请发 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor/issues)，GitHub 上的留言不保证看得到。

### 方法三 · 不装，只复制提示词

打开 [`system-prompt.md`](system-prompt.md)，把代码块里的全部内容复制成系统提示词。
任何 AI 都能用，纯文字聊天窗口也行，只是每换一个对话要再贴一次。

> 装不上、想让 AI 代装、想看原理，见 [使用手册](usage-guide.md) 的「怎么装」。

## 怎么用

1. 说清年级和想学的内容，或者干脆只说「帮我学数学」。
2. 讲完看编号：不懂就回编号，懂了回「明白」。
3. 做完题把答案发回去让它批改 —— 这一步最容易被跳过，但效果最好。

> 小学阶段请家长或老师陪着一起用。让孩子先自己试一遍，再看讲解和答案；AI 生成的内容不要直接抄到作业或试卷上。

可以直接照抄的开场：

- 我是二年级学生，今天语文课学了《小蝌蚪找妈妈》，帮我讲讲。
- 人教版，五年级，分数的基本性质，帮我讲讲并出点题。
- 我高一，化学方程式配平总是不会。

平时用得上的按这张表找：

| 你想做什么 | 看哪个 |

## 用哪个 AI 效果更好

同一套提示词，换个模型效果会不一样：长规则跟不跟得住、能不能读图、能不能写文件，差别都在这里。

建议用主流工具配较新的模型。缺哪项都还能用，只是会降级，不会变成不能用。四项能力的差别和降级表现，见 [使用手册](usage-guide.md) 的「用哪个 AI 效果更好」一节。

## 现在做到哪一步了

**这套规则已经可以正常用来辅导学习**，但还在打磨，不会替你打「完全验证」的包票。

- **自查过**：规则之间不打架，文件层面自检全通过。自检只看文件，不看模型表现。
- **实测过**：在 WorkBuddy 上跑过一次真实交互，另有几轮本机抽样，其中一次跑完完整三轮流程。这些样本只用来改规则，**不算逐项验收**。
- **还没做**：换不同厂商的 AI、换较新的模型，把每条规则逐项核对一遍；也还没请未参与制作的人真正试用过。规则只是文字，能提高遵守的概率，不能保证。
- **会遇到**：讲解偏深、题目太难或太简单、动画在你设备上放不出来。这属于现阶段正常情况，反馈过来比默默关掉更有用。

欢迎到 [Gitee 仓库提 issue](https://gitee.com/hejsky/ai-study-tutor/issues)，贴对话截图就行，不用懂代码，也不用懂 git。

最帮得上忙的反馈：孩子哪句话没听懂、哪道题难度不对、讲解或答案哪里有错、动画能不能打开、用的哪一版教材。老师与家长提供的真实课堂案例尤其有用。

## 已知限制

动画要能显示网页才动得起来；写文件要看 AI 有没有这个能力；规则效果随模型而异。完整 9 条见 [使用手册](usage-guide.md) 末尾「附：客观能力边界」。

# 助力学（AI 学习助教）

**给 1~12 年级学生的 AI 学习助教提示词与工作流** · 可复制使用 / 可安装为 WorkBuddy Skill · `v1.0.0` · MIT 许可 · 公开实践阶段

把一节没听懂的课、一道不会的题、一张拍下来的课本页发给 AI，它会像一位熟悉你年级的老师那样：**讲给你听 → 画给你看 → 出题练你 → 帮你改 → 安排你复习**。全程说你能听懂的话，配图与动画保持轻量，几乎不产生额外费用。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 分科目教法 | 语文 / 数学 / 英语 / 物理 / 化学各有专属工作流；其他科目走通用兜底 |
| 年龄适配 | 小学低年级 / 小学高年级 / 初中 / 高中四档语言分层，讲解、习题、答案、批改四处一致 |
| 练习闭环 | 三层分层习题、答案后置、按步骤或踩分点批改、费曼自测、3 天复习计划 |
| 轻量可视化 | 教学示意图 + SVG/CSS 代码动画（几 KB、3~8 秒、只讲一个过程），**不生成大型视频** |
| 对话引导 | 不会描述需求也没关系，AI 一次只问一个问题，最多三问就开工；支持拍照 |
| 教材版本对齐 | 说出人教版 / 北师大版 / 辽师大版等版本，AI 会贴合该版本的术语叫法与章节进度；不说则按课标通用讲法，**且不会编造教材页码或课文原文** |

完整介绍见 [`usage-guide.md`](usage-guide.md)，可直接照抄的示例见 [`examples/`](examples/)。

## 快速开始

> 首选上方「让 AI 帮你装好」。若当前 AI 不支持自动安装，或你更愿意自己动手，用下面两种方式都可以。

### 方式 A · 复制提示词（最通用，任意 AI 对话都能用）

1. 打开 [`system-prompt.md`](system-prompt.md)，把代码块内**全部内容**复制为 System Prompt。
2. 第一轮像聊天一样描述情况即可，例如：

   > 我是二年级学生，今天语文课学了《小蝌蚪找妈妈》，帮我讲讲。

   说得少也没关系，说「帮我学数学」AI 会来问你；教材、作业、试卷也可以直接拍照。**顺带说一句课本版本（如「人教版」）会更贴合你的课本**，不知道也没关系。
3. 做完题把答案发回去让 AI 批改——这一步最容易被跳过，却恰恰是最有效的巩固环节。

> 最低环境要求：能读图并生成示意图的 AI；播放代码动画需要能打开 `.html` 文件的浏览器。不同工具与模型的效果差异、以及怎么选，见下文「用哪种 AI 工具与模型」。

### 方式 B · 安装为 WorkBuddy Skill

整个仓库目录本身就是一个 Skill 包：从 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 下载后，复制到用户级目录即可被自动发现：

```
~/.workbuddy/skills/ai-study-tutor/
```

入口是根目录的 [`SKILL.md`](SKILL.md)，其中 `name` 与目录名保持一致；中文名为「助力学」。

> 这一步同样可以交给 AI 代劳：把上面的仓库地址发给它，说「帮我装好这个 skill」即可。

## 用哪种 AI 工具与模型

同一套提示词，换一个 AI 工具或换一个模型，辅导效果可能明显不同——这是模型能力差异，不是提示词写错了。差别主要落在四处：

| 能力 | 跟不上时会怎样 |
|------|----------------|
| 长提示词遵循 | 年龄语言档位、一次只问一个问题、答案后置、按步骤批改这些文字规则容易被漏掉 |
| 多模态读图 | 教材、作业、试卷照片读不了，只能靠文字描述 |
| 图像与动画 | 生成不了教学示意图，或只能给代码、没法直接播放 SVG/CSS 动画 |
| 文件写入 | 产物只能给代码块和建议路径，不会真的建 `animations/` / `images/` 文件夹 |

**建议**：优先用主流 AI 工具搭配较新的模型，并确认它同时支持「读图 + 长提示词 + 文件写入」。较新的模型对长篇规则的遵循通常更稳；不必纠结具体品牌或排行榜，工具与模型更新很快，以你手头这一版的实际能力为准。

**效果不理想时**：先换个更新的模型试一次；若仍出现讲解偏深、答案跑到题目前面、一次抛出一串问题，可以把 [`examples/`](examples/) 里的示例附在提示词后作为对照，或到 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 提 issue 反馈——这类真实反馈正是本项目在实践阶段最需要的（见下文「项目状态」）。

## 目录结构

```
ai-study-tutor/
├── SKILL.md                  WorkBuddy Skill 入口（中文名「助力学」）
├── README.md                 本文件，Gitee 仓库首页
├── system-prompt.md          ★ 唯一权威的可复制提示词
├── usage-guide.md            人话版使用说明、FAQ、能力边界
├── check_repo.py             仓库合规自检（维护用，使用本项目不必运行）
├── CHANGELOG.md / LICENSE / .gitignore / .gitattributes
└── examples/                 示例，可直接照着用
    ├── grade2-fraction-lesson.md     二年级分数讲解示例
    ├── guided-dialogue.md            对话引导示例
    ├── math-g5-fraction-pie.html    可播放的分数代码动画
```

仓库只放静态内容，保持扁平。`animations/` 与 `images/` 是 AI **运行时按需创建**的产物目录，不随仓库分发，也不预置空文件夹；规模前提为「一个学生 / 一个家庭」。

## 项目状态：仍在实践验证中，欢迎一起把它变好

`v1.0.0` 是首个公开版本，**现在就能正常用来辅导学习**，但它还不是「定型成品」：这是一套靠真实使用不断校准的助教提示词，规则写得再细，也要在真实的年级、课本和不同 AI 平台上试过才知道稳不稳。

- **已自查**：开发期做过同源仿真，覆盖年龄适配、引导模式、分科目路由、代码动画、产物归档、教材版本防幻觉等；分数代码动画有可播放实物。
- **仍待实测**：目标部署平台上的实际模型行为抽样验证；教材真实内容检索尚未接入，版本信息目前只用于对齐术语与进度。文本规则只能提高模型遵守的概率，不能替代实测。
- **使用预期**：偶尔出现讲解偏深、题目太难或太简单、动画放不出来的情况，属于这个阶段的正常现象。反馈过来比默默关掉更有价值。

**最帮得上忙的反馈**：孩子哪句话没听懂、哪道题难度不合适、讲解或答案哪里有错、动画在你设备上能不能打开、用的是哪一版教材；老师与家长提供的真实课堂案例尤其有用。

**参与方式（不用懂代码、不用懂 git）**：到 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 提一条 issue，把遇到的问题或对话截图贴上去即可；熟悉 Gitee 的话，也欢迎直接改提示词、补示例。详细的用例清单与测试报告属开发期资料，**不随本仓库分发**。

# 助力学（AI 学习助教）

**给 1~12 年级学生的 AI 学习助教提示词与工作流** · 可复制使用 / 可安装为 WorkBuddy Skill · `v1.0.0` · MIT 许可

把一节没听懂的课、一道不会的题、一张拍下来的课本页发给 AI，它会像一位熟悉你年级的老师那样：**讲给你听 → 画给你看 → 出题练你 → 帮你改 → 安排你复习**。全程说你能听懂的话，配图与动画保持轻量，几乎不产生额外费用。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 分科目教法 | 语文 / 数学 / 英语 / 物理 / 化学各有专属工作流；其他科目走通用兜底 |
| 年龄适配 | 小学低年级 / 小学高年级 / 初中 / 高中四档语言分层，讲解、习题、答案、批改四处一致 |
| 练习闭环 | 三层分层习题、答案后置、按步骤或踩分点批改、费曼自测、3 天复习计划 |
| 轻量可视化 | 教学示意图 + SVG/CSS 代码动画（几 KB、3~8 秒、只讲一个过程），**不生成大型视频** |
| 对话引导 | 不会描述需求也没关系，AI 一次只问一个问题，最多三问就开工；支持拍照 |
| 教材版本对齐 | 说出人教版 / 北师大版 / 辽师大版等版本，AI 会贴合该版本的术语叫法与章节进度；不说则按课标通用讲法，**且不会编造教材页码或课文原文** |

完整介绍见 [`usage-guide.md`](usage-guide.md)，可直接照抄的示例见 [`examples/`](examples/)。

## 快速开始

> 首选上方「让 AI 帮你装好」。若当前 AI 不支持自动安装，或你更愿意自己动手，用下面两种方式都可以。

### 方式 A · 复制提示词（最通用，任意 AI 对话都能用）

1. 打开 [`system-prompt.md`](system-prompt.md)，把代码块内**全部内容**复制为 System Prompt。
2. 第一轮像聊天一样描述情况即可，例如：

   > 我是二年级学生，今天语文课学了《小蝌蚪找妈妈》，帮我讲讲。

   说得少也没关系，说「帮我学数学」AI 会来问你；教材、作业、试卷也可以直接拍照。**顺带说一句课本版本（如「人教版」）会更贴合你的课本**，不知道也没关系。
3. 做完题把答案发回去让 AI 批改——这一步最容易被跳过，却恰恰是最有效的巩固环节。

> 环境要求：支持图像生成的 AI；若要播放代码动画，需要能打开 `.html` 文件的浏览器。纯文本聊天里 AI 会给出代码 + 建议保存路径。

### 方式 B · 安装为 WorkBuddy Skill

整个仓库目录本身就是一个 Skill 包，复制到用户级目录即可被自动发现：

```
~/.workbuddy/skills/ai-study-tutor/
```

入口是根目录的 [`SKILL.md`](SKILL.md)，其中 `name` 与目录名保持一致；中文名为「助力学」。

> 这一步同样可以交给 AI 代劳：把仓库网址发给它，说「帮我装好这个 skill」即可。

## 推送到 Gitee

### 1. 先跑合规自检

```bash
cd ai-study-tutor
python check_repo.py
```

脚本会检查：必备文件是否齐全、UTF-8 无 BOM、LF 换行、单文件与总体积、是否夹带本机绝对路径或密钥特征、Markdown 相对链接、README 是否保持纯 Markdown（无裸 HTML 标签与 shell 占位符）、发布版本号是否一致。检查范围只包含**会提交进仓库的文件**，IDE 自动生成的 `.idea/` 等本地配置不参与，因此在开发机上直接运行也不会误报。全部通过后再提交。

### 2. 提交与推送

```bash
git init
git add .
git commit -m "feat: 助力学 Skill v1.0.0"
git remote add origin https://gitee.com/YOUR_GITEE_ID/ai-study-tutor.git
git push -u origin master
```

> 把 `YOUR_GITEE_ID` 换成你的 Gitee 用户名。**不要用尖括号包住占位符**——尖括号在 shell 中是输入重定向符，照抄会执行失败。
> 分支名以你在 Gitee 建仓库时的默认分支为准（`master` 或 `main`）。认证方式按 Gitee 当前要求配置，**不要把账号、令牌或任何凭据写进仓库文件**。
> 首次发布建议打标签：`git tag v1.0.0 && git push origin v1.0.0`。[`CHANGELOG.md`](CHANGELOG.md) 里带 `v` 的开发期编号都是**未发布的内部计数**，不是发布版本。

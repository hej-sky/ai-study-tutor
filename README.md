# 助力学（AI 学习助教）

**给 1~12 年级学生的 AI 学习助教提示词与工作流** · 可复制使用 / 可安装为 WorkBuddy Skill · `v1.5.0` · MIT 许可 · 公开实践阶段

把一节没听懂的课、一道不会的题、一张拍下来的课本页发给 AI，它会像一位熟悉你年级的老师那样：**讲给你听 → 画给你看 → 出题练你 → 帮你改 → 安排你复习**。全程说你能听懂的话；配图够用就好，动画直接用 SVG/CSS 代码生成，不生成按秒计费的大型视频，也不要求所用 AI 具备图像生成能力。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 分科目教法 | 语文 / 数学 / 英语 / 物理 / 化学各有专属工作流；其他科目走通用兜底 |
| 年龄适配 | 小学低年级 / 小学高年级 / 初中 / 高中四档语言分层，讲解、习题、答案、批改四处一致 |
| 练习闭环 | 三层分层习题、答案后置、按步骤或踩分点批改、费曼自测、3 天复习计划 |
| 轻量可视化 | 教学示意图 + SVG/CSS 代码动画（几 KB、3~8 秒、只讲一个过程），**不生成大型视频** |
| 对话引导 | 不会描述需求也没关系，AI 一次只问一个问题，最多三问就开工；支持拍照 |
| 讲解后分支 | 讲完给出带编号的知识点清单，回编号只细讲没懂的那一点，回「明白」继续；细讲会换讲法而非复读，反复不懂的点会在批改与复习计划里加重 |
| 教材版本优先 | 人教版 / 北师大版 / 辽师大版等版本是**第一解析与对齐字段**：先定版本口径再讲，首轮回显首行、每轮导航条首字段都是版本；未指定不会默认人教版，中途改版本只增量更新且优先于同轮其他动作；不会编造教材页码或课文原文 |

完整介绍见 [`usage-guide.md`](usage-guide.md)，可直接照抄的示例见 [`examples/`](examples/)。

## 快速开始

> 首选上方「让 AI 帮你装好」。若当前 AI 不支持自动安装，或你更愿意自己动手，用下面两种方式都可以。

### 方式 A · 复制提示词（最通用，任意 AI 对话都能用）

1. 打开 [`system-prompt.md`](system-prompt.md)，把代码块内**全部内容**复制为 System Prompt。
2. 第一轮像聊天一样描述情况即可，例如：

   > 我是二年级学生，今天语文课学了《小蝌蚪找妈妈》，帮我讲讲。

   说得少也没关系，说「帮我学数学」AI 会来问你；教材、作业、试卷也可以直接拍照。**开场顺带说一句课本版本（如「人教版」「北师大版」）最贴合你的课本**，不知道也没关系——AI 会写「未指定」，不会默认人教版。首轮回显以版本开头（教材版本 / 科目 / 年级 / 知识点），**看错了当场说一句就能改**。
3. 讲完后哪一点没懂，直接回编号（如「2」）让它单独细讲；懂了回「明白」继续。做完题把答案发回去让 AI 批改——这一步最容易被跳过，却恰恰是最有效的巩固环节。

> **最低环境要求**：任意能进行多轮对话的 AI 即可，纯文本环境也能完整使用——示意图与动画默认以 SVG/CSS 代码交付，展示能力由工具自行判定（见 `system-prompt.md` 开头）。能读教材照片、能打开 `.html` 文件播放动画会更好，但都不是必需。不同工具与模型的效果差异、以及怎么选，见下文「用哪种 AI 工具与模型」。

### 方式 B · 安装为 WorkBuddy Skill

整个仓库目录本身就是一个 Skill 包：从 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 下载后，复制到用户级目录即可被自动发现：

```
~/.workbuddy/skills/ai-study-tutor/
```

入口是根目录的 [`SKILL.md`](SKILL.md)，其中 `name` 与目录名保持一致；中文名为「助力学」。

**更省事：直接下载现成的技能包。** 仓库 [`release/`](release/) 里有已打包好的 [`ai-study-tutor-v1.5.0.zip`](release/ai-study-tutor-v1.5.0.zip) 和 [`avatar-512.png`](release/avatar-512.png)：把 ZIP 内容解压到上面的目录（`SKILL.md` 要在第一层，别多套一层文件夹），或在 WorkBuddy 里用「添加技能 → 上传技能」直接选这个 ZIP。这个包已补齐市场所需字段、去掉维护文件，比直接拿整个仓库更干净；构建方式与各平台上架步骤见 [`release/发布清单.md`](release/发布清单.md)。

> 这一步同样可以交给 AI 代劳：把上面的仓库地址发给它，说「帮我装好这个 skill」即可。

## 用哪种 AI 工具与模型

同一套提示词，换一个 AI 工具或换一个模型，辅导效果可能明显不同——这是模型能力差异，不是提示词写错了。差别主要落在四处：

| 能力 | 跟不上时会怎样 |
|------|----------------|
| 长提示词遵循 | 年龄语言档位、一次只问一个问题、答案后置、按步骤批改这些文字规则容易被漏掉 |
| 多模态读图 | 教材、作业、试卷照片读不了，只能靠文字描述 |
| 图像与动画 | 没有图像生成能力时，示意图改用代码或静态图描述；渲染不了 HTML/SVG 时，动画只能给代码，需另存 `.html` 用浏览器打开 |
| 文件写入 | 产物只能给代码块和建议路径，不会真的建 `animations/` / `images/` 文件夹 |

**建议**：优先用主流 AI 工具搭配较新的模型；若还能同时支持「读图 + 长提示词 + 文件写入」效果更好，但**这三项都不是必需项**——缺了会降级，不是不能用。较新的模型对长篇规则的遵循通常更稳；不必纠结具体品牌或排行榜，工具与模型更新很快，以你手头这一版的实际能力为准。

**效果不理想时**：先换个更新的模型试一次；若仍出现讲解偏深、答案跑到题目前面、一次抛出一串问题，可以把 [`examples/`](examples/) 里的示例附在提示词后作为对照，或到 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 提 issue 反馈——这类真实反馈正是本项目在实践阶段最需要的（见下文「项目状态」）。

## 目录结构

```
ai-study-tutor/
├── SKILL.md                  WorkBuddy Skill 入口（中文名「助力学」）
├── README.md                 本文件，Gitee 仓库首页
├── system-prompt.md          ★ 唯一权威的可复制提示词
├── usage-guide.md            人话版使用说明、FAQ、能力边界
├── eval-checklist.md         部署后规则核对（仅维护者，使用者无需阅读）
├── check_repo.py             仓库合规自检（维护用，使用本项目不必运行）
├── CHANGELOG.md / LICENSE / .gitignore / .gitattributes
├── release/                  发布物料：技能包 ZIP、头像、构建脚本与发布清单（维护用）
└── examples/                 示例，可直接照着用
    ├── few-shot.md                  四场景示例合集（§A 年龄 / §B 引导 / §C 分支 / §D 版本）
    ├── math-g5-fraction-pie.html    可播放的分数代码动画
    └── svg-animation-template.html   可复用的动画骨架
```

仓库除 `examples/` 与 `release/` 两个分类目录外保持扁平；里面的文件都是静态内容，`check_repo.py` 与 `release/build_release.py` 是需手动运行的维护脚本，不会在辅导过程中自动执行。`release/` 供人下载技能包，AI 运行时不会读它；`animations/` 与 `images/` 是 AI **运行时按需创建**的产物目录，不随仓库分发，也不预置空文件夹；规模前提为「一个学生 / 一个家庭」。

## 项目状态：仍在实践验证中，欢迎一起把它变好

`v1.5.0` **现在就能正常用来辅导学习**，但它还不是「定型成品」：这是一套靠真实使用不断校准的助教提示词，规则写得再细，也要在真实的年级、课本和不同 AI 平台上试过才知道稳不稳。本版把「省 Token」从压字数改成裁冗余——宁可篇幅上浮，也不能让学生因为少了一句话而没读懂。

- **已自查**：开发期做过同源仿真，覆盖年龄适配、引导模式、分科目路由、代码动画、产物归档、教材版本防幻觉等；分数代码动画有可播放实物；全部规则通过 `check_repo.py` 文件层自检，但自检不验证模型行为。
- **已实测（单点样本，v1.1.0）**：在 WorkBuddy 上完成过一次真实交互实测（九年级 · 人教版物理「电流与电压、电阻的关系」），据此修订了展示能力声明、首轮体量、分轮策略与可视化等规则。该样本**只用于修订规则，不是按清单逐项验收**；当时还没有 A~I 组核对清单，未留下逐项勾选记录。逐条用例见 [`eval-checklist.md`](eval-checklist.md)。
- **本机基线抽样（2026-11-09）**：v1.4.0 跑了 4 个干净会话样本（初中物理两档模型、低年级数学、版本纠正第 2 轮），发现首轮篇幅偏长与低年级出现书面词两处偏差；v1.5.0 修订后又跑了 3 个复测样本（初中物理两档模型、低年级数学），确认低年级版本字段降级生效、术语白话解释与类比等理解必需项齐全，「版本纠正优先」在复测中未触发、沿用 v1.4.0 的结论。版本首字段、未指定不默认人教版等核心规则成立。**篇幅问题的处理是上调参考区间（600~1100 字）以容纳完整讲解，不是把输出压短**；复测首轮 1014~1144 字，最高一例仍略高于 1100 字参考线，超长时的分轮兜底仍需实测。**这不是跨平台实测**，两轮抽样都只走到第 2 轮，可视化、习题、批改与复习闭环均未触发。
- **仍待实测**：跨厂商 AI 工具与较新模型上的表现、批改闭环与费曼自测、3 天复习计划、跨年级档位 / 科目 / 教材版本，以及教材真实内容检索（尚未接入）。单点样本不宜外推，文本规则只能提高模型遵守的概率。
- **使用预期**：偶尔出现讲解偏深、题目太难或太简单、动画放不出来的情况，属于这个阶段的正常现象。反馈过来比默默关掉更有价值。

**最帮得上忙的反馈**：孩子哪句话没听懂、哪道题难度不合适、讲解或答案哪里有错、动画在你设备上能不能打开、用的是哪一版教材；老师与家长提供的真实课堂案例尤其有用。

**参与方式（不用懂代码、不用懂 git）**：到 [Gitee 仓库](https://gitee.com/hejsky/ai-study-tutor) 提一条 issue，把遇到的问题或对话截图贴上去即可；熟悉 Gitee 的话，也欢迎直接改提示词、补示例。逐条用例见 `eval-checklist.md`。
